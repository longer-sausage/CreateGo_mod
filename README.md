# CreateGo 地图编辑器

面向 Minecraft 1.21.1 / NeoForge 21.1.244 的服务端权威地图、NPC 与节点对话编辑器。机械动力与 Sable 是可选依赖；地图结构采用机械动力“蓝图与笔”生成的标准压缩结构 NBT。

## 构建与安装

```powershell
.\gradlew.bat build
Copy-Item .\build\libs\creatego-0.4.2.jar "D:\PCL\.minecraft\versions\1.21.1-NeoForge_21.1.244\mods\"
```

构建需要 Java 21。Gradle Toolchain 会在允许联网时自动下载匹配的 JDK。

服务端与每一个客户端都必须安装相同版本的 JAR。客户端还需要 Modern UI 3.13.0.1 或更高版本，双方都需要 Bad Packets 0.8.2 或更高版本。CreateGo JAR 已内嵌 Dynamic Dimensions AR Edition 0.9.1，无需单独安装该动态维度模组。地图、NPC、对话图和皮肤由服务端保存；客户端不需要手工复制这些数据。

## 获取工具

管理员进入世界后执行：

```text
/give @s creatego:map_editor
/give @s creatego:npc_editor
```

两个工具都要求 2 级管理员权限。NPC 编辑器只在地图编辑器为该玩家动态创建的隔离维度中生效。

## 地图工作流

地图编辑器根据玩家状态提供两种模式：

- 普通模式：逐项显示已有地图，每页五张；点击地图只是选中，随后可以选择“进入所选地图”或“配置所选地图”。配置界面不会创建维度或绑定地图；未绑定时“保存 NPC”和“退出地图”不可用。
- 隔离编辑模式：每次进入地图都会为当前玩家动态创建一个全新的完全空白维度，并直接使用同一配置界面。点击“保存 NPC”才会把当前会话内的全部 NPC 草稿写入配置；“退出地图”只返回进入前的位置并删除临时维度。

推荐流程：

1. 输入地图 ID 后点击“新建地图”。地图 ID 仅保留英文字母、数字、下划线和连字符，并统一转为小写；新地图创建后自动打开配置。
2. 使用机械动力“蓝图与笔”保存结构，把鼠标悬停在配置界面的蓝图框上并滚动滚轮选择文件；按住 Shift 滚轮每次跳过五项。
3. 点击“上传所选蓝图作为地图结构”。上传只修改持久结构，不影响已经运行的隔离编辑会话。
4. 返回目录，选中地图并点击“进入所选地图”。服务端会创建唯一临时维度，在最低建筑坐标 `(0, 0, 0)` 放置结构，再按绝对坐标生成全部 NPC。
5. 使用 NPC 编辑器创建或修改 NPC。NPC 编辑器中的应用、删除、皮肤和对话操作都只修改当前会话草稿；点击地图编辑器中的“保存 NPC”才会一次性保存全部 NPC 的绝对坐标、朝向、名字、皮肤和其余数据。
6. 点击“退出地图”返回进入前的位置。通过命令、传送、死亡换维或登出离开时会直接丢弃上次“保存 NPC”之后的修改并永久删除临时维度。若在临时维度退出游戏，服务端会先恢复进入前的位置，再由原版流程保存玩家数据。

同一地图可以由多名管理员同时进入；每个人拥有独立维度，方块、实体和未提交 NPC 草稿不会相互干扰。地图绑定只会由“进入所选地图”创建。删除地图需要连续点击两次确认，并会关闭该地图的所有活动会话、删除元数据和 `config/creatego/maps/<地图 ID>` 下的蓝图文件。

单张蓝图上限为 32 MiB。每次进入都从持久蓝图和 NPC 数据重新生成，退出后不会保留临时维度的方块数据。

## NPC 与皮肤

- 手持 NPC 编辑器右键方块，会在方块上方创建 NPC，并面向创建者。
- 手持工具右键 NPC 会打开 NPC 编辑界面；空手或其他物品右键会进入对话。
- NPC 无 AI、无重力、无碰撞推动且无敌。
- NPC 坐标使用隔离编辑维度内的绝对坐标保存。
- 默认皮肤依据 NPC UUID 从九套原版宽臂模型中稳定随机选择。
- 自定义皮肤放在 `config/creatego/skins`，支持 64×64 或旧版 64×32 PNG，单文件上限为 1 MiB。
- 皮肤按 SHA-256 去重保存，并由客户端按哈希向服务端请求。

## 对话节点

- 入口节点：每张图唯一，不能删除；右侧输出连接第一个执行节点。
- 对话节点：节点内可直接编辑从一行开始自动增高的 NPC 文本框，并拥有一个“继续”输出。
- 选项节点：节点内可直接编辑自动增高的提示文本；每个选项都有独立输出端口，可动态增删。
- 分支节点：按顺序判断多个条件；每个条件有独立输出，并带一个兜底“默认”输出。
- 安全结束：任意节点的输出没有连接后续节点时，对话会自动安全结束。

节点编辑器使用 Modern UI 的抗锯齿矢量画布和原生文本组件，整体布局参考 ComfyUI：

- 鼠标滚轮以光标位置为中心缩放，实用范围为 25%–400%；左下角也提供 `−`、缩放百分比、`+` 和“适应”按钮。
- 在画布空白处按住左键拖动可平移画布；节点内除按钮、端口和编辑框外的区域都可拖动节点。
- 从节点右侧彩色输出端口拖到目标节点左上角彩色输入端口即可连接，拖动时实时显示连线。
- 每条连线中点都有可点击控制点；选中后可在右侧查看并删除该连线。
- 对话节点直接提供自动增高的文本编辑框；选项与分支节点直接显示每项配置、端口名称和连接含义。
- 选项与分支可在节点本体或右侧属性面板中动态添加、删除；每一项始终拥有独立输出端口。
- 节点、端口和连线共用同一套世界到视口换算；缩放会生成真实布局尺寸，点击区域与画面保持一致。
- 玩家对话界面使用 Modern UI 的响应式底部卡片、滚动选项和悬停/按下状态反馈。

分支条件支持：

- `INVENTORY_ITEM`：`key` 为物品 ID，例如 `minecraft:diamond`；值为背包和副手总数量。
- `SCOREBOARD`：`key` 为计分板目标名；值为玩家对应分数。
- `PLAYER_TAG`：`key` 为玩家标签；存在为 `1`，不存在为 `0`。
- `PERMISSION`：比较玩家是否达到 `value` 指定的权限等级。

运算符支持 `≥`、`>`、`=`、`≠`、`<`、`≤`。分支判断与游标校验都在服务端执行，客户端不能伪造条件结果。

## 服务端数据

实例级数据统一位于：

```text
config/creatego/
├─ maps.json
├─ maps/<地图 ID>/structure.nbt
└─ skins/<SHA-256>.png
```

`maps.json` 是可读 JSON，包含地图元数据、NPC 绝对坐标和完整对话图。蓝图与皮肤使用独立文件，避免状态同步重复传输大型二进制数据。动态编辑维度只存在于会话期间，不属于持久地图数据。
